# 강담태권도 홈페이지

서울 동작구 신대방동 · 보라매 / 용인대학교 태권도학과 석사 김지환 관장.
별도 빌드 도구 없이 `index.html`을 브라우저로 열면 바로 확인됩니다.

## 파일 구조

```
├─ index.html            메인 페이지 (전체 섹션)
├─ assets/
│  ├─ css/style.css      브랜드 디자인 시스템 + 전체 스타일
│  ├─ js/main.js         네비/스크롤/카운터/FAQ/폼 검증
│  └─ img/               (실제 사진 교체용 폴더)
└─ README.md
```

## 확인이 필요한 부분

아래 두 가지는 추정으로 넣었으니 실제와 다르면 알려주세요.

1. **평일 마감 시각** — JSON-LD(`openingHours`)에 `Mo-Fr 12:00-20:00`으로 넣었습니다. 7시부 수업 종료 시각 기준으로 조정 필요.
2. **전문 줄넘기반(화·목) 시작 시간** — 시간표에는 "상담 시 안내"로 표기해 두었습니다.

추가로 넣으면 좋은 것: 관장님 **국기원 단증 / 지도자·심판 자격 / 수상 경력** —
[index.html](index.html)의 `.profile-list` 안에 `<!-- TODO -->` 주석 위치가 있습니다.

## 도장 사진

`assets/img/` 에 도장 실사진 8장이 들어 있습니다. (바탕화면 원본을 JPG 82% 품질로 변환)

**현재 노출 중 (5장)**

| 파일 | 쓰이는 곳 |
|---|---|
| `hall-main.jpg` | 시설 섹션 큰 칸 — 메인 수련장 |
| `rope-class.jpg` | 시설 — 줄넘기 수업 공간 |
| `equipment.jpg` | 시설 — 발차기 타이어·수련 장비 |
| `lobby.jpg` | 시설 — 현관·신발장 |
| `entrance-door.jpg` | 시설 — 캐릭터 출입문 |

**보류 중 (3장) — 아이들 얼굴이 나옵니다**

`class-stance.jpg` / `class-group.jpg` / `class-sitting.jpg`

보호자 초상권 동의가 확인되기 전까지 노출하지 않습니다.
[index.html](index.html) 시설 섹션 아래 주석 블록에 마크업이 준비돼 있으니,
동의가 확인되면 `<!--` 와 `-->` 두 줄만 지우면 바로 노출됩니다.

**해상도 주의** — 현재 사진은 가로 470~480px입니다. 큰 칸에서는 다소 흐리게 보일 수 있으니,
원본 사진(휴대폰 원본)이 있으면 가로 1600px 이내 JPG로 다시 저장해 같은 파일명으로 덮어쓰면 됩니다.

**다른 곳에 사진을 더 넣으려면** — 프로그램 카드(`.prog__thumb`), 관장 사진(`.master__photo`),
히어로(`.hero-card`)의 `<svg>` 를 아래 한 줄로 바꾸면 됩니다.

```html
<img src="assets/img/파일명.jpg" alt="설명" loading="lazy"
     style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;">
```

좌표는 `37.4945782, 126.9145016` 입니다.

## 상담 폼 연동

`assets/js/main.js`의 **6번 블록** 주석 위치에 발송 로직을 넣으면 됩니다.

- 간단하게: [EmailJS](https://www.emailjs.com/) 또는 구글폼 `formResponse` POST
- 서버가 있다면: `fetch('/api/apply', { method:'POST', body: new FormData(form) })`
- 상담 채널: 채널톡/카카오 상담톡 스크립트를 `</body>` 직전에 삽입

현재는 프론트 검증(이름·휴대폰 형식·나이·동의 체크)까지만 동작하며, 실제 전송은 되지 않습니다.
